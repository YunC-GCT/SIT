# 03 — 规划器统一输出与实验指标

**What to build:** A*、Dijkstra、PRM、RRT 和 RRT* 可以独立运行并产生统一的 JSON 规划结果，记录原始路径、算法参数、随机种子和比较指标。

**Blocked by:** 01 — 运行批次与统一 JSON 契约基础

**Status:** resolved

- [x] 所有已注册规划算法接受同一地图、起终点和参数契约
- [x] 成功、无解和参数错误使用统一状态与结构化错误
- [x] 原始路径使用统一 row/col 坐标结构输出
- [x] 随机算法支持并记录随机种子
- [x] 记录规划耗时、节点数、路径长度、是否找到路径和算法参数
- [x] 研究模式支持一次运行多个算法并生成可比较结果
- [x] 使用固定地图和种子验证结果可复现，并覆盖无解路径场景

## Answer

已完成规划器统一输出与实验指标：

- 新增 `path_planner.src.planner_pipeline`，将 A*、Dijkstra、PRM、RRT 和 RRT* 收敛到统一 Python API，输出版本化 JSON 中的 `raw_path`、算法参数、随机种子和规划指标。
- 新增 `path_planner.json_pipeline` 和兼容入口 `path_planner/run_planner.py`，读取 `map_pipeline` 的 success JSON，支持单算法、研究模式、多算法和 JSON 参数覆盖；每次运行创建独立批次、manifest、结果和日志。
- 为工厂增加统一参数校验、默认参数展开和局部随机源；PRM、RRT、RRT* 使用显式种子，固定地图和种子可复现。
- 失败、无解和非法参数均输出 `failed` 状态及包含模块、阶段、输入、原因和建议动作的结构化错误；研究模式不会把失败候选伪装成成功结果。
- 空路径的 JSON shape 固定为 `[0, 2]`，保持下游契约可校验；README 和 API_INDEX 已同步更新。

验证：`python -m unittest discover -s tests -v` 通过 25 个测试；`pytest -q` 通过 25 个测试；`compileall` 和 `git diff --check` 通过。
