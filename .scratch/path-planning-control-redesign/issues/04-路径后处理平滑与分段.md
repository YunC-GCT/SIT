# 04 — 路径后处理、基础平滑与路径段生成

**What to build:** 将任意规划器的原始路径转换为经过基础平滑、离散采样、碰撞复核和最大段长限制的可执行路径段 JSON；平滑失败时安全回退到已验证原始路径。

**Blocked by:** 02、03

**Status:** resolved

- [x] 提供可替换的平滑器接口，第一版使用自研自然边界分段三次样条和累计弧长参数化
- [x] 以不超过配置采样间距离散曲线，保持起点和终点
- [x] 对采样点及连接线执行基础碰撞检查
- [x] 按最大段长分解路径，支持任意步长和方向角
- [x] 生成包含起终点、位移、方向角、转角、距离、预计时间和运动类型的路径段 JSON
- [x] 样条数值异常、越界或碰撞时回退原始路径并记录原因
- [x] 覆盖平滑、碰撞、分解、起终点保持和回退行为的测试

## Answer

新增 `path_postprocess` 独立模块及 CLI。模块使用累计弧长自然边界三次样条，
对曲线采样后执行栅格碰撞复核，失败时回退到已验证原始路径，并输出最大段长、
方向角、转角、物理距离、预计时间和运动类型。结果通过统一 JSON 契约写入独立
运行批次；测试覆盖平滑、碰撞回退、分段、端点保持、原始路径校验和 CLI。
