# 采样策略配置落地

实现 PRM 重试、可选自适应步长、RRT* 首解/优化分阶段预算。统一工厂验证参数，API/CLI 均可显式传参，主入口加载 YAML。未改变算法身份，未加入 A* 兜底。

## 当前配置

- PRM：20000 点、15 可见近邻、边长 15，失败再以 30000 点新建路图。重试的实际点数、各轮参数与结果通过 outputs.search_diagnostics 返回，失败亦保留；开阔场景可覆盖为 6000/15/40。
- RRT：步长上限 5、目标偏置 0.05、迭代上限 200000。新增 adaptive_step 可选参数，根据局部障碍距离缩小步长，碰撞后逐次减半到 1。固定模式保持可用。
- RRT*：同上，首解前最多 15 秒，首解后最多 2 秒或 2000 次迭代，并受总迭代上限限制。记录首解时间、首解迭代、停止原因与总时间。时间预算为循环边界软上限，依机器负载不同会改变最终路径。

工厂出厂值保留固定模式，配置文件中的覆盖才启用上述主入口配置。直接 API 调用须显式传参；全部新增参数均经过验证。

## 实际效果与回退

原随机任务组 1、原种子与起终点复测，见 [初档记录](sampling-adaptive-strategies.json) 和 [PRM 首档调整记录](sampling-adaptive-final-config.json)。后者记录时自适应仍为 true，不代表最终 YAML 的自适应 false 配置已完成复测。

- Room8：自适应 RRT 约 4.14 秒成功、RRT* 约 5.11 秒成功，均通过默认后处理；原记录两者均超时。
- Room8：PRM 最终 20000/15/15 首档约 3.56 秒成功，通过默认后处理；初步 6000/15/20 加 30000 重试曾超时。
- Maze4：PRM 返回 NO_PATH，RRT 超时，RRT* 首解预算耗尽；未解决。
- Random20：自适应 RRT 超时、RRT* 15 秒未找到首解，劣于此前固定步长候选。故最终 YAML 中 adaptive_step 默认 false，仅供 Room 等场景显式启用；不把局部改善当普遍改善。初档 Random PRM 约 0.78 秒成功，但用的是 6000/15/20，与最终 PRM 首档不同。

最终 YAML 的固定 RRT + 新预算组合尚未完成全图复测，不能宣称最终配置已验收通过。后续需按场景选择固定/自适应策略，并比较相同预算及独立任务上的成功率和首解时间。
