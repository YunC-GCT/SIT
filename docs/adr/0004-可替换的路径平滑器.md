# 可替换的路径平滑器

状态：accepted

第一版路径后处理使用自行编写的分段三次样条插值，不引入 SciPy 等外部成熟库；但平滑器必须通过独立适配接口接入，后续可以切换成熟库实现而不修改路径后处理流程、JSON 契约或运动控制器。自研实现采用自然边界条件和累计弧长参数化，生成曲线后进行密集采样、基础碰撞复核和失败回退；复杂参数优化留给后续研究。

## 考虑过的方案

- 直接把成熟库绑定到路径后处理器：暂不采用，因为当前容器依赖不确定且希望保留算法自主实现。
- 让每个规划算法各自实现平滑：拒绝，因为会破坏模块独立性和算法比较的一致性。

## 后果

自研样条需要承担数值稳定性和边界条件测试；适配器边界保留了未来替换成熟库的路径。任何平滑失败都必须回退到已验证原始路径，并在 JSON 结果中明确标记。
