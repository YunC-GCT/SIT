# Triage 标签

工程技能使用五个标准 triage 角色。下表定义这些角色在本仓库本地 Issue 追踪器中的状态名称。

| 标准角色 | 本仓库状态 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交由 agent 实现 |
| `ready-for-human` | `ready-for-human` | 必须由人类处理 |
| `wontfix` | `wontfix` | 不会处理 |

当技能提到某个标准角色时，必须使用表中对应的本仓库状态名称。若以后调整本仓库的状态词汇，只修改表格第二列。
